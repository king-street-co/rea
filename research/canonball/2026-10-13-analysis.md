## 2. Canonball as observed (live site v0.1.160)
- **Stack (rea plus bundle strings, high confidence):**
  - Next.js App Router and React; `x-powered-by: Next.js`.
  - Hosted behind Google (`via: 1.1 google`, envoy), likely Cloud Run or Firebase App Hosting. The exact host is unverified.
  - **Supabase** for auth and DB (about 90 references).
  - **Open Library** for book metadata and covers (`search.json`, `/works/`, `/b/id/`).
  - **PostHog** for analytics and **Sentry** for errors.
- **Nav:** Home, Find, Plan, Live, Clubs, Profile, Resources (Pairings, About, Blog). Tagline: "Find It · Read It · Live In It".
- **Features (from the marketing page; in-app depth unverified because I didn't sign in):**
  - Whispersync discovery with community-verified Kindle+Audible pairings.
  - Reading tracker: sessions, streaks, progress.
  - Vocabulary builder: daily words from classic texts, shown with the source quote.
  - Book clubs: snake draft to pick the calendar, schedule coordination.
  - Wrap Party quizzes: community trivia, hosted live with scores.
  - Bounties and challenges: badges, seasons, verification bounties.
  - Blog and guides (SEO).
- **rea endpoint hints:** client routes and params include `book`, `club`, `tab`, `bookTab`. It also handles `Retry-After`, which suggests rate-limited API calls.
- **Gaps:** there's no `sitemap.xml` (it 404s or is empty), which is weak for SEO. Data model, RLS policies and server code can't be seen without the repo.

## 4. Gaps and opportunities (ranked)
1. **Whispersync / format-aware library ("own it once, read and listen").**
   - Unify Kindle and Audible progress into one position; verified pairings are already the moat.
   - Add a "which edition to buy" engine with price alerts.
   - Nobody else does this.
2. **Club OS that beats Fable.**
   - Keep the snake draft, scheduling and live quizzes.
   - Add spoiler-gated chapter rooms keyed to each member's progress.
   - Add milestone pacing and "catch-up" summaries that are human-written or clearly labeled opt-in AI. Fable's controversy shows labeling matters.
3. **Frictionless import and portability.**
   - Goodreads CSV and Kindle/Audible library import, plus full export.
   - This is the #1 switching barrier, and Goodreads has no API.
4. **Literary depth as identity (the "serious reader" niche).**
   - Vocab from what *you* are reading, quote and annotation journals, canon lists and "read the canon" seasons.
   - Spaced-repetition review.
   - Differentiates from the mass-market Fable and Goodreads.
5. **Ratings, reviews and recommendations with transparency.**
   - Nuanced ratings (half stars, tags) and explainable recs, e.g. "because you finished X and your club liked Y".
   - Opt-in AI with no auto-generated judgments of users.

Also worth doing: a sitemap and SEO book pages generated from Open Library data, a PWA/mobile app, and shareable Wraps for growth.

## 5. Phased build plan (Next.js + Supabase + Open Library, PostHog/Sentry)
Each phase follows the video loop: plan, then rea research notes (in king-street-co/rea `research/`), then an agent builds in the canonball repo, then review, then tests and a preview deploy.

**Phase 0: Foundations (1 week)**
- Locate the repo and get the agent's access.
- Add CI (lint, typecheck, Playwright smoke), Supabase migrations in git, RLS audit, `sitemap.ts` and `robots`.
- Add PostHog funnels for signup, first book added and club joined.

**Phase 1: MVP parity core (2–3 weeks)**
- Shelves (want/reading/read plus custom), ratings and reviews.
- Goodreads CSV import and export.
- Annual goal and stats page.
- Edition model: `works`, `editions` (format: ebook/audio/print, ASIN, ISBN), `pairings` (ebook_edition, audio_edition, verification votes).

**Phase 2: Differentiators (3–4 weeks)**
- Unified read/listen progress: log the percent or timestamp in either format and convert using the pairing.
- Pairing verification bounties v2.
- Edition buy guide with deep links (affiliate later).
- Vocab from the user's current books with spaced repetition (SM-2).

**Phase 3: Club OS (3–4 weeks)**
- Progress-gated, spoiler-safe chapter rooms using Supabase Realtime.
- Milestones and reminders through email or push.
- Snake draft v2.
- Live Wrap Party quizzes over Realtime channels.
- Moderator tools.

**Phase 4: Social and discovery (4+ weeks)**
- Follows and feed, plus shareable monthly and yearly Wraps (OG images).
- Explainable, opt-in recommendations over a pgvector embedding of books.
- SEO book and pairing pages.

**Phase 5: Mobile and monetization**
- PWA, then Expo app.
- Premium tier: advanced stats, unlimited clubs, price alerts. Affiliate edition links.

**Key risks**
- Amazon has no public Whispersync or progress API, so pairing stays community-verified with manual or "share" progress logging. Don't scrape behind logins.
- Open Library data gaps (ASINs) need a curated edition table.
- AI trust: label everything and keep it opt-in.
